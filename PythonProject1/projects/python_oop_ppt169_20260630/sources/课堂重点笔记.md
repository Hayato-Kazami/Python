# Python 进阶 - 面向对象

## 面向对象入门

### 思想

编程中有3大编程思想：

- 面向`过程`：你脑海中规划的实现路径，代码就按这个实现路径去写
  - 脑袋怎么想的，代码就是怎么写的
  - 比如写文件，脑袋想的是：打开、写入、关闭，那么代码就是这样写的
  - 过程用代码实现
- 面向`对象`：你想要做什么事情，就找一个对象干活
  - 脑袋怎么想的，无所谓的，我只要找合适的对象干活
  - 比如写文件，找一个能写文件的对象，去把事情干了，至于它怎么干，不关心
- 面向`函数式` 编程：以后再说



举例：

- 面向过程：我想要打扫教室，我想的是：扫地、拖地、擦桌子，那么我的动作就是扫地、拖地、擦桌子
- 面向对象：我想要打扫教室，我会喊胖虎去干活；
  - 胖虎怎么干，我不关心
  - 我需要先培养好胖虎



面向对象的编程，主要有2大动作：

1. 先生产对象
2. 再`对象干活`



#### 对象

面向对象中的对象，就是指的是`实体`，实体是现实世界中`事物`的描述；

实体有属性和行为；

#### 面向对象实现的流程

核心是让对象去干活，为了得到这个效果，步骤是：

1. 先设计一个对象
2. 创建对象
3. `对象干活`



### 设计一个对象：设计一个类class

对象（实体），实体是有属性和行为的；

- 属性，数值的记录，用`变量` 可以记录；
- 行为，动作的记录，用`函数`进行记录；

将属性（变量），行为（函数），打包在一起，就可以设计出来一个对象；



再Python中，可以使用`class` 关键字，去设计一个对象，即设计一个类；



基础语法：

```python
class 类名称(object):
    属性
    属性
    
    行为
    行为
    
    
# 或
class 类名称:
    属性
    属性
    
    行为
    行为
```

- `(object)` 可以写也可以不写，写和不写一个效果，功能后面学习（类继承相关）

示例

```python
# ```设计```一只存在于代码中的狗，应该有的属性和行为
class Dog(object):      # 新的代码结构，类结构，可以再内部封装变量和函数
    name = "豆包"
    age = 5
    color = "黄"

    def sleep(self):	# 函数的传参，默认带上self
        print("睡觉了")

    def eat(self):
        print("吃饭了")

    def wangwang(self):
        print("汪汪汪，咬你")
```

### self的作用

在类中，函数，默认编写的时候PyCharm会自动填入self作为参数传入；

self本身表示的是自己，即：哪个对象调用的，self就表示谁

```python
class Student:

    def sleep(self):
        # self的作用，表示的是自己，哪个对象调用的sleep，self就是哪个对象本身
        print(f"大家好，我是：{self.name}")
        print(type(self), self)
        # print(name)       # 访问自己的属性，必须使用self.访问

stu1 = Student()
stu2 = Student()

stu1.name = "王丽红"       # 属性，可以后期添加
stu2.name = "周杰轮"       # 属性，可以后期添加

stu1.sleep()        # 这一行执行，self表示是stu1
stu2.sleep()        # 这一行执行，self表示是stu2

print(stu1)
print(stu2)

```

如上代码

- `stu1.sleep()`，则self表示`stu1`
- `stu2.sleep()`，则self表示`stu2`



在访问自己的属性的时候，是需要`self.`才可以

类中的函数的传参self，我们不需要传递，python解释器会自动传入，即：

- `stu1.sleep()`，的时候，会自动执行为：`stu1.sleep(stu1)`
- `stu2.sleep()`，的时候，会自动执行为：`stu2.sleep(stu1)`



### 类中函数的传参

```python
class Student(object):

    def say(self, height, addr):
        # self.name 表示访问自己内部的专属name属性记录
        # height 和 addr 使用的是外部传参
        print(f"我叫{self.name}，身高{height}厘米，住在{addr}")

stu = Student()
stu.name = "王大锤"
# 类中的函数，和普通函数一样，传参等没啥区别
# 唯独，形式参数第一个必须是self
# 实际参数，可以不理会self（自动传入）
stu.say(172.55, "合肥高新区")
```

- 类中定义的函数，接收参数，第一个必须是`self` （除非是类函数或者静态函数）
- 在调用的时候，可以不传入`self`，python解释器会自动传入的



### 类中函数的叫法

从面向对象阶段开始，关于函数的叫法有2种：

- 函数：写在类外面的函数，和类无关
  - 英文：`function`
- 方法：写在类里面的函数，和类有关，称之为方法

## 魔法（魔术）方法

魔法方法，是类中内置的，特定名称和参数的方法；

即，只要你的方法名字是某个特定的名称，则会拥有特定的功能；



魔法方法，如果你不写，每个类都有默认的（Python提供的默认实现）



### `__init__魔法方法（构造方法）`

首先，名字必须是：`__init__`，只要你的方法名字是这个，就拥有特定功能：

1. 创建类对象的时候，此方法会自动执行；
2. 创建类对象的传参，会自动传入这个方法；

示例

```python
class Student(object):

    # 名字必须是 __init__ 才有特殊功能
    def __init__(self, name, age):
        print("我执行了")
        print(f"我是{name}，今年{age}岁")

print("1")
# 创建类对象的时候，__init__自动执行，同时创建类对象的传参，自动传给了__init__
stu = Student("王大锤", 11)
print("2")
```



#### 实际使用场景

```python

# 规划，学生应该有2个属性，name和age
class Student:

    def __init__(self, name, age):
        # 传入的name只是传入数据而已，不是类的属性
        # 需要将其转换为类的属性，即self.的模式
        self.name = name        # 将外部传入的name，转为内部属性name
        self.age = age          # 将外部传入的age，转为内部属性age

    def say(self):
        print(f"我是{self.name}, 今年{self.age}岁")

# 通过__init__ 在创建类对象的时候，直接提供各自的属性
stu1 = Student("王大锤", 11)
stu2 = Student("周杰轮", 22)
stu1.say()
stu2.say()

```

通过`__init__`，完成在创建（构建）类对象的时候，就完成了其属性的赋值，所以`__init__`魔法方法，也被称之为构造方法；



### `__del__`魔法方法（析构方法）

名字，固定：`__del__`，作用：

- 当类对象被删除的时候，会自动执行



类对象被删除有2个场景：

- `del 类对象`，手动删除类对象
- 类对象的作用域结束，会被自动删除
  - Python程序退出之前，会被自动清理



示例场景

```python
# 面向对象：一切活都让对象干
# 需求，完成文件的读写功能，既能读也能写
# 实现，以面向对象思想，搞一个对象，这个对象能读能写，让对象干活
# 1
class FileOperator:

    def __init__(self, file_path):
        # 对象被创建的时候，就打开文件了
        self.fw = open(file_path, "w", encoding="utf-8")
        self.fr = open(file_path, "r", encoding="utf-8")

    def __del__(self):
        self.fr.close()
        self.fw.close()

    def read(self):
        print(self.fr.read())

    def write(self, text):
        self.fw.write(text)
        self.fw.write("\n")
        self.fw.flush()         # 将缓冲区内容写入硬盘
# 2
fo = FileOperator("hello.txt")
# 3
fo.write("我是帅哥")
fo.read()

```



### `__str__`魔法方法

作用：当类对象被转换字符串的时候，会以`__str__`方法的返回值作为转换结果；

```python
class Student:

stu = Student("周杰轮", 11)

print(stu)      # print函数会自动将内容转为字符串后再显示
```

### `__eq__`魔法方法

`eq:equals`

作用：判断2个类对象是否相等；

示例

```python
# 只要狗的名字和颜色相同，我就认为相同
class Dog:

    def __init__(self, name, color):
        self.name = name
        self.color = color

    def __eq__(self, other):		# 接收一个other的形参，表示另一个被比较的
        # self是自己，other是另一个
        if self.name == other.name and self.color == other.color:
            return True
        return False
    	# __eq__方法，应该返回Ture or False

dog1 = Dog("阿黄", "黄色")
dog2 = Dog("阿黄", "黄色")

print(id(dog1))
print(id(dog2))
print(dog1 == dog2)     # dog1 == dog2 本质就是 dog1.__eq__(dog2)

```

- 如果不在类中自己提供`__eq__`，默认类对象的相等判断是比较内存地址是否相同；
- 如果自己提供了`__eq__`，则用自己提供的逻辑，决定是否相等；



示例2

```python
"""
1. 设计Student类，提供学生的name、age、gender性别
2. 创建2个学生对象比较是否相等
要求，名字年龄性别 全部相等就是相等，否则不相等
提示：__eq__实现
"""

class Student(object):
    def __init__(self, name, age, gender):
        self.name = name
        self.age = age
        self.gender = gender

    def __eq__(self, other):
        if self.name == other.name and self.age == other.age and self.gender == other.gender:
            return True

        return False

stu1 = Student("aa", 11, 'male')
stu2 = Student("aa", 11, 'male')
print(stu1 == stu2)

```

## 面向对象三大特征



三大特征：封装、继承、多态



### 封装（私有）

封装：将属性和行为，封装到class类中；

封装的特征：

- 属性和行为，在class中同时出现（class类的特征）
- `属性和行为，可以设置为私有`



#### 私有的语法

私有：属性和方法，只能通过`self.`方式访问，无法被类对象访问；

如何让属性和方法变成私有，只需要名字前面加上`__`前缀即可

示例

```python

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        self.__money = 100

    def say(self):
        self.__add_money()
        print(f"我叫{self.name}，今年{self.age}岁，我有{self.__money}元钱")

    def __add_money(self):
        self.__money += 100

stu = Student("周杰轮", 11)
print(stu.name)
print(stu.age)
stu.say()

stu.__add_money()			# 类对象无法访问私有的__add_money方法
print(stu.__money)			# 类对象无法访问私有的__money属性

```



#### 私有的作用

如果将属性设置为私有，则类的对象，是无法直接访问和修改的；就保护了这个私有属性不被类对象随意篡改；

如果类对象想要访问或修改这个私有属性，则需要类中提供公开的访问方法，做中转；



示例

```python
class Worker:

    def __init__(self, name):
        self.name = name
        self.__money = 0      # 工资

    def show_money(self):
        print("验证工人身份，验证通过")
        print(f"工人：{self.name}，工资：{self.__money}")

    def work(self):
        print(f"工人：{self.name}工作了1天，工资++")
        self.__money += 1000

worker1 = Worker("周杰轮")
worker2 = Worker("王丽红")

worker1.show_money()
worker1.work()
worker1.show_money()
```

`__money` 是私有，2个工人对象，是无法直接修改这个变量的。

- 如果想要增加钱，只有一个方法：调用`work` 干活



示例

```python
class Student:

    def __init__(self, name):
        self.name = name
        self.__age = 0            # 必须是数字，且在14~50

    def input_age(self, age):
        # 检查
        if not isinstance(age, int):        # isinstance(a, b) 判断a和b是否是同一个class
            print("年龄必须是整数，滚出去")
            return

        if age < 14:
            print("学校不收童工，滚出去")
            return

        if age > 50:
            print("老东西太老了，滚出去")
            return

        self.__age = age

    def show_age(self):
        print(self.__age)


stu = Student("王大锤")

stu.input_age(18)
stu.show_age()
```

- `__age` 是私有， 不允许随意修改，只能通过`input_age`修改
- `input_age` 在修改前会做各类验证，确保修改的值是OK的；
